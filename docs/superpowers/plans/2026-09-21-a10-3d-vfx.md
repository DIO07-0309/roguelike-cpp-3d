# A10 — 3D 特效系统优化

> 设计 spec: docs/superpowers/specs/2026-09-21-a10-3d-vfx-design.md
> 实施计划: docs/superpowers/plans/2026-09-21-a10-3d-vfx.md

## 目标
为 3D 模式实现真正的 3D 特效，替代当前的 2D 发光片。

## 阶段

### Phase 1: 3D 粒子系统
- 扩展 ParticleSystem 支持 3D 空间（y 轴高度）
- 修改 HD2DDrawItem 支持粒子类型
- 在 hd2d_renderer.cpp 绘制 3D 粒子

### Phase 2: 3D 光效（Bloom/Glow）
- 实现后处理 Bloom shader
- 接入 3D 渲染管线
- 让特效发光

### Phase 3: 3D 网格特效
- 剑弧用 3D 网格（有厚度）
- 光束用 3D 圆柱体
- 冲击波用 3D 球体

### Phase 4: 3D 模型动画（可选）
- 需要外部 3D 模型资源
- 暂时跳过，等待美术资源

## 关键文件
- src/game/rendering3d/hd2d_scene_builder.cpp
- src/game/rendering3d/hd2d_renderer.cpp
- src/game/systems/particle_system.h/cpp
- src/game/systems/game_renderer.cpp

- 2D 模式保持现有特效
- 3D 模式使用新 3D 特效
