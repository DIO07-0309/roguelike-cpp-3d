# P4 地形审美升级 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 对 3 群系 × 4 类地形做群系专属造型语言升级，让监牢/火山/虚空一眼可辨；所有新增顶点落在原 bbox 内，面数严格高于基线。

**Architecture:** 全部改动集中在 `art_src/scripts/blender_models_terrain.py`：`_biome_decor(p, c, biome, kind)` 是群系点缀入口（按 biome × kind 追加主题件），4 个 builder（build_wall/floor/stairs/door）共享几何骨架、仅传 `PALETTES` 配色。本轮把每群系的造型语言从"几根小点缀"升级为"主题化造型层"。经 `export_one(name)` 覆盖 JSON、`preview_one(name)` 重渲染预览。新增独立闸门 `tools/check_p4_assets.js` + `tools/p4_baselines.json`（19 件磁盘 JSON，bbox≤基线、faces>基线）。

**Tech Stack:** Blender 5.2.1 + Blender MCP；`blender_lib`（协议 A）；C++17 + raylib；gtest；node 闸门。

**Spec:** `docs/superpowers/specs/2026-11-18-p4-terrain-design.md`（含用户 4+2 项拍板）

## Global Constraints

- 协议 A：`export_json` 做 `(x,y,z)→(x,z,-y)`；JSON y=高度、z=纵深；正面为 Blender −Y（引擎 +Z）。
- schema `{name, vertices[x,y,z,r,g,b], faces}`；明暗烘顶点色。
- 低段数采样 bbox：半径敏感件（圆盘/球）保持原段数，靠 bbox 内部装饰补细节。
- **面数严格 > 基线**（用户拍板），无绝对门槛、无上限；bbox 各轴不超基线（容差 0.01）；贴地 y_min=0 不变。
- **闸门 19 个磁盘文件 / 19/19**（用户拍板）：基线从当前 JSON 实测生成；prison/volcano 的 wall v0 无独立文件，由无后缀基准代偿（基准精修即 v0 精修），不新增资产；void 的独立 v0 单独精修。
- **阻塞性视觉验收**（用户拍板）：每类地形把三群系并排 `look()`，确认造型语言明显不同；通过标准=缩略图 2 秒内可分辨群系归属且主题元素清晰可辨；未达标必须迭代重做，作为交付门槛。
- 不改资产名、不改 `PALETTES` 配色常量、不改 `TERRAIN_BUILDERS` 注册/别名关系、不改 `_try_terrain_3d` 的 v0 回退契约。
- 三群系主题：forgotten_prison=铁栅/铆钉/地牢石砌/锁链；ash_volcano=熔岩池/黑曜石/火山岩层/火星；void_abyss=悬浮符文阵/紫晶/空间裂隙/幽光。
- 21 张预览全部重生成（21 个 TERRAIN_BUILDERS key，含 2 个 v0 别名图）；完成后同步桌面包并哈希校验。
- 禁用 MCP 工具：`get_viewport_screenshot` / `get_world_state_snapshot` / `drain_human_activity`；预览走 `look()`。
- 每次 MCP 调用 `user_prompt` 填用户原话："P4（21 件地形审美升级）"。
- 全量门：ctest 90/90、mesh_asset_test 全绿（AllTerrainModelsAndWallVariantsExist）、fn_length 0、world_validator、P3b 17/17、P3 8/8、A22 150/150 不退化。

## Review Focus

- **换色伪装成升级**：三群系只是颜色不同、主题元素不可辨 → 阻塞性跨群系并排审图（每类一个任务）。
- **bbox 撑破**：低段数采样经验失效、主题件外扩 → 闸门 bbox 六向 + 审图。
- **tile 网格破坏**：新增件超出 32×32 占地 → bbox 闸门守住 x/z 基线。
- **贴地契约破坏**：地板/台阶主题件悬空或入地 → 闸门 y_min + mesh_asset_test FeetAtGroundLevel。
- **别名/命名失效**：改 v0 关系或资产名 → 不改名约束 + AllTerrainModelsAndWallVariantsExist + 19/19 闸门。
