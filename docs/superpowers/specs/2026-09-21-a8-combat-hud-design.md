# A8 — 战斗 HUD 优化 v1 (2026-09-21)

## 目标

优化战斗 HUD 的视觉表现和交互友好度，提升战斗体验。

**成功标准：**
- 信息清晰：所有战斗信息一眼可见（HP/技能/小地图/资源）
- 美观统一：风格与游戏一致，像素艺术风格
- 交互友好：冷却提示明确、技能图标易识别、小地图可缩放
- 性能优先：不增加渲染负担，60FPS 稳定

## 架构

保留现有 `GameRenderer::draw_hud()` 架构，逐步优化各组件：

1. **HP/XP bar** - 像素风双层边框 + 高光 + 动态颜色（绿→黄→红）
2. **技能栏** - 冷却图标旋转 + 数字倒计时 + 升级标识
3. **小地图** - 标记颜色区分（怪物红/Boss 金/楼梯蓝/物品绿）
4. **金币/资源** - 像素图标 + 数字 + 圣物数量

**数据流不变** - 每帧从 Player/Monster/GameMap 读取，不维护第二套状态。

**渲染顺序** - 游戏场景 → HUD（半透明叠加）→ UI 面板（完全覆盖）

## 数据流

**不变** - 每帧从现有系统读取：

1. **HP/XP bar** - `Player->combat.current_hp`, `Player->xp`, `Player->xp_to_next`
2. **技能栏** - `Player->skills.active_skills`, 各技能的冷却状态
3. **小地图** - `GameMap->isExplored()`, `GameMap->isVisible()`, `Player->tile`, 怪物/Boss/楼梯位置
4. **金币/资源** - `Player->gold`, `Player->key_count`, `Player->relics.size()`

**不维护第二套状态** - 所有数据每帧实时读取，不缓存不复制。

## 错误处理

1. **空指针保护** - `if (!player) return;` 在 `draw_hud()` 开头
2. **字体未加载** - `if (g_font_loaded)` 保护所有文本绘制
3. **边界检查** - HP/XP ratio 限制在 [0, 1]，位置不越界
4. **小地图空数据** - 无怪物/Boss/楼梯时不绘制标记
5. **技能栏空** - 无技能时不绘制技能栏

**降级策略** - 资源未加载时使用文本替代，不崩溃

**调试输出** - 关键路径添加 `LOG_DEBUG`，不影响性能
