## 1. 目标

对 9 地标 + 8 护甲做"细节微调"，把审查中发现的"docstring 承诺但未建模"和"大面积素面"
补上，提升视觉丰富度。不改 gameplay / 命名 / 契约 / 坐标协议 / bbox。

## 2. 目标 / 非目标 / 反目标

**目标**
- 地标：补齐明确的造型缺口（抓痕、链环、碎石、火舌分层、符文刻纹、龟裂等）。
- 护甲：补齐素面部位（胸甲刻槽、更多铆环/鳞片、肩甲附加片、兜帽内衬、垂冰等）。
- 所有新增顶点落在原 bbox 内；贴地 y_min=0 契约不变。

**非目标**
- 不改面数硬指标（这两类本就健康），除非用户拍板设提升目标。
- 不重新设计造型、不改配色常量、不改共用 `_base_chest` 骨架尺寸。

**反目标（做了就算失败）**
- 撑破原 bbox、破坏贴地契约、破坏 AllNineLandmark/AllEightArmor 契约。
- 改资产名导致 `kGroundItemModels` / `item.cpp` 映射失效。

## 3. 约束（协议 A + 低段数采样经验）

- 导出 `(x,y,z)→(x,z,-y)`；JSON y=高度、z=纵深。
- schema `{name, vertices[x,y,z,r,g,b], faces}`；明暗烘顶点色。
- **低段数采样 bbox**：半径敏感件（肩球/圆盘/瓶身）保持原段数，靠 bbox 内部装饰补细节。
- bbox 边界（逐件见审查报告 §2/§3）：地标 y_min=0、占地各异；护甲多数 x±10~12、高 16.2、深[-3.8,4.3]。
- 契约门：ctest 90/90、mesh_asset_test 全绿、AllNineLandmark/AllEightArmor 存在。
