# arena_* 5 件精修立项设计（2026-11-20）

状态：**已确认（用户拍板：arena 5 件 + 沿用惯例验收）**

## 1. 现状

`blender_models_arena.py` 的 5 个 builder（A14 原版，从未审美精修）：
- `arena_barrel` 472 面：木桶身+2 铁箍+警示带+盖+引信
- `arena_totem` 468 面：八棱石座+柱身+符文腰带+石首+顶冠双角
- `arena_rock` 196 面（全库最低）：压扁球+侧碎石+棱面片
- `arena_spike` 272 面：铁基板+5 圆锥钉+4 铆钉
- `arena_pool` 792 面：不规则液面厚片+内层+2 气泡

这是全库面数最低的一类（均值 440），且是战斗房高频可见物。P5 只做过位置抬升（陷阱可见性），零造型投入。

## 2. 目标 / 约束

**目标**：5 件全部精修到面数 ≥1000（照 P3 门槛），造型更丰富（细节层次清晰），bbox 不超原值。
**约束**：
- 协议 A（Z-up，y=高度，导出 y↔高度）；bbox 各件不超原基线（容差 0.01）；贴地 y_min 保持（rock 基线 -0.08）
- 不改资产名、不改配色常量、不改 gameplay/映射（ArenaObjectType → 模型名不变）
- 用现有 palette 键新增细节，不引入新颜色常量
- 遵守 CLAUDE.md 全部规范（函数≤40 行、单一职责、语义命名、改前影响分析、改后 Code Review、单次≤300 行、可维护性优先）
- 全量门：ctest 91/91、mesh_asset_test 契约、fn_length 0、world_validator、P3/P3b/P4/P5 闸门不退化
- 全量预览重生成审图 + 桌面包同步（exe 到根目录，禁碰初代版）+ 最终审查

## 3. 造型方案（bbox 内加细节）

| 资产 | 当前短板 | 精修方向（bbox 内） |
|---|---|---|
| barrel | 桶身光板、铁箍细 | 加木纹竖板+钉头+警示斜纹+引信火苗分层+底圈 |
| totem | 石首平、柱身素 | 加面部浮雕（眉/鼻/口）+符文刻纹+腰带垂饰+底座分层 |
| rock | 就 3 块球/片 | 加碎裂棱面+苔痕+小碎石簇+裂缝线（仍是低模风但层次丰富） |
| spike | 钉子光滑 | 加倒刺环+血槽+基板格栅+锈斑+铆钉帽 |
| pool | 液面整片 | 加涟漪环+毒气泡簇+边缘结晶+漂浮碎屑 |

半径敏感件保持段数，靠 bbox 内部装饰补面。面数目标 ≥1000（rock/spike 需大幅补面）。
