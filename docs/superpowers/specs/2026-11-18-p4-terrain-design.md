## 1. 现状分析（只读调查结论）

### 1.1 资产与生成

- 生成脚本：`art_src/scripts/blender_models_terrain.py`，`TERRAIN_BUILDERS` 注册 **21 件逻辑资产**
  （3 群系 × [floor / stairs / door + wall 的 v0/v1/v2 三变体 + 无后缀别名]）。
- 磁盘实有 **19 个** `terrain_*.json`：`_biome_decor` 的 wall 变体中，void 群有独立 `v0`，
  prison / volcano 的 `v0` 由无后缀基准别名代偿（运行时 `_try_terrain_3d` 在 v0 缺失时回退基准名，
  二者几何相同，契约 `AllTerrainModelsAndWallVariantsExist` 已明确接受这种等价）。
- 4 个 builder：`build_wall(c, variant, biome)` / `build_floor(c, variant, biome)` /
  `build_stairs(c, biome)` / `build_door(c, biome)`；三群系共享同一套几何骨架，仅传不同 `PALETTES`。

### 1.2 同质化根源（关键）

- **几何骨架三群系完全共用**：floor 的 2×2 石板、stairs 的 4 级台阶+两侧栏、
  door 的石框+门板+铆钉、wall 的砖砌+壁柱/拱券，三群系只有配色不同。
- **群系差异全压在 `_biome_decor` 的小点缀**：forgotten_prison 直接 `return`（零点缀）、
  ash_volcano 仅 3 条熔岩细缝 / 3 熔岩条+2 黑曜刺、void_abyss 仅 3 扁球 / 3 符文条+2 紫晶。
  这些点缀尺寸 1.2–2.2，在 TILE=32 的尺度下视觉存在感极低 —— 预览里三个 floor 几乎一模一样。
- wall 的 v0/v1/v2 有真实结构差异（v0 拱券+双壁柱、v1 纯砖+横石带+裂纹、v2 中央壁柱+盾徽+苔痕），
  但**三群系的对应变体仍是同一套结构换色**。

## 2. 目标 / 非目标 / 反目标

**目标**
- 三群系的 floor / stairs / door / wall 一眼可辨：每群系有专属造型语言与主题元素。
- 同一群系内 wall 的 v0/v1/v2 在三群系间也要拉开差异（不只是换色）。
- 所有新增顶点落在原 bbox 内；贴地 y_min=0 不变。

**非目标**
- 不在原 bbox 外扩占地（tile 网格 32×32 必须对齐，外扩会破坏拼接）。
- 不改资产名、不改 `_try_terrain_3d` 的 v0 回退契约、不改 `PALETTES` 配色常量。
- 不为凑面数而堆细节；面数只要求严格 > 基线。

**反目标（做了就算失败）**
- 撑破 bbox、破坏贴地契约、破坏 `AllTerrainModelsAndWallVariantsExist`。
- 把三群系做成"换色皮肤"（即本次要解决的病根）。

## 3. 约束

- 协议 A：`export_json` 做 `(x,y,z)→(x,z,-y)`；JSON y=高度、z=纵深；正面为 Blender −Y。
- schema `{name, vertices[x,y,z,r,g,b], faces}`；明暗烘顶点色。
- **低段数采样 bbox 经验**：半径敏感件（圆盘/球体）保持原段数，靠 bbox 内部装饰补细节。
- bbox 各件基线见 §1.3，容差 0.01；地面件新增细节只能贴地 y≈0~5（不能悬空）。
- 三群系主题：
  - forgotten_prison（监牢）：铁栅 / 铆钉 / 地牢石砌 / 锁链
  - ash_volcano（火山）：熔岩池 / 黑曜石 / 火山岩层 / 火星
  - void_abyss（虚空）：悬浮符文阵 / 紫晶 / 空间裂隙 / 幽光
- 改动只发生在 `blender_models_terrain.py` 的 4 个 builder + `_biome_decor`（按 builder 级决策落地）。
- 全量门：ctest 90/90、mesh_asset_test 全绿、fn_length 0、world_validator、P3b 17/17、
  P3 8/8、A22 150/150 不退化。
- 21 张预览全部重生成 + 逐张审图；**"一眼可辨"为阻塞性验收**（跨群系并排对比，未达标迭代重做）；
  完成后同步桌面包并哈希校验。
- 每次 MCP 调用 `user_prompt` 填用户原话："P4（21 件地形审美升级）"。
