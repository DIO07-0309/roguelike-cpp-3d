## 5. 伤害公式

```
base_damage  = max(1, attacker_attack − defender_defense × def_factor)
variance     = 0.8 + random(0..400) / 1000  →  [0.8, 1.2]
final_damage = max(1, base_damage × variance × stage_multiplier)
```

| 攻击类型 | 防御取值 | def_factor |
|----------|----------|------------|
| PHYSICAL | physical_defense | ×0.5 |
| MAGICAL | magical_defense | ×0.6（折损更重；但魔抗数值普遍低于物防，净效果仍偏利于魔法） |
| TRUE | 0（无视防御） | ×0.0 |

> 数据来源: enemies.json 30 怪中 11 个 `pdef > mdef`、6/6 boss 全部 `pdef > mdef`
> （如 demon_lord pdef 15 / mdef 11）。因此魔法虽按 0.6 折损，打在更低数值上，
> 实际减伤仍通常小于物理。G10.2 引入 type-aware resistance 时本节文档未同步，
> 且代码内注释曾误写为 "magic pierces slightly more"（0.6 是折损**更重**，方向反了）。

## 6. 玩家有效攻击力计算链

```
step_1 = combat.get_effective_attack()
       = (base_attack + 等级增长) + atk_flat_modifier (武器装备)

step_2 = step_1 × buff_mult
       buff_mult = 1.0
         + 0.20 × attack_up 层数     (每层+20%, 上限3层)
         + 0.15 × berserk 层数      (每层+15%, 上限2层)
         + 0.08 × blessing 层数     (每层+8%, 上限3层)
         + 0.06 × momentum 层数     (每层+6%, 上限5层)
         + 0.10 × adrenaline 层数   (每层+10%, 上限3层)
         − 0.12 × blind 层数        (每层-12%, 上限2层)

step_3 = step_2 × relic_sum
       relic_sum = 1.0
         + 0.10 (war_drum)
         + 0.08 (hunter_gloves)
         + 0.06 (ancient_crown)
         + 0.10 (dragon_heart)
         + 0.12 (infinity_orb)
         + 0.00~0.20 (blood_chalice, HP越低越高)

final = max(1, step_3)
```

**最大理论倍率**（全buff+全relic）：buff_mult≈2.0, relic_sum≈1.66 → **约 3.3× 基础攻击力**。

## 12. SimHei 中文字体说明

`resource_manager.cpp` 中的 `_build_font_cp()` 在启动时自动扫描 `src/` 和 `resources/` 下所有 `.cpp/.h/.json` 文件，提取全部 Unicode 码位 ≥ 0x2000 的字符，构建字体图集。

- 字体路径：`C:/Windows/Fonts/simhei.ttf` → `assets/simhei.ttf`
- 字号：大字体 32px，小字体 18px
- **不再需要手工维护码位数组**。任何新增的中文内容会被自动覆盖。

## 快速参考：一剑砍在怪上伤害多少？

以 **Lv5 玩家 + 稀有长剑 (base_damage=7) + 2 层 attack_up**  vs  **F5 兽人** 为例：

```
玩家 ATK = 10(基础) + 4×1(等级) + 7(武器) = 21
buff_mult  = 1.0 + 0.20×2 = 1.40
有效 ATK   = 21 × 1.40 = 29

兽人 HP    = 30 × 2.20 = 66
兽人 DEF   = 3
伤害       = max(1, 29 − 3×0.5) × 1.00(stage1) × variance(0.8~1.2)
           ≈ 27 × 1.0 × 1.0 = 27

兽人存活 ≈ 66/27 ≈ 3 刀（3 段 combo 刚好打死）
```

同样的剑打 **F15 石像守卫**：

```
玩家 ATK  = 10 + 14×1 + 13(传说剑) + buff + relics ≈ 45~55
守卫 HP   = 90 × 9.00 = 810
守卫 DEF  = 14
伤害      = (45 − 14×0.5) × variance = 38 × ~1.0 = 38
存活      ≈ 810/38 ≈ 21 刀（需要多轮 combo + 技能配合）
```
